External Simulation Extension
=============================

Overview
--------

The external simulation extension enables residual computations from the Fault Diagnosis Toolbox to be exported as a Functional Mock-up Unit (FMU). The extension automates the process of extracting model information, generating residual computation code, and packaging it into a portable simulation unit.

Metadata Extraction and Residual Generation
-------------------------------------------

When the extension is invoked, an external simulation module is created. This module extracts metadata from the model, including signals and parameters that are later exposed as FMU variables.

Based on the provided *Gamma* object and the selected residual equation index, the toolbox generates residual computation code. This generated code forms the computational core of the FMU.

Runtime Execution
-----------------

Execution of the generated residual model is handled by the ``FmuRuntime`` class. This class provides two main methods:

- ``build_runtime``: Constructs the runtime representation of the residual computation model.
- ``step``: Executes a single simulation step by passing input signals and parameters to the generated model and returning the computed result.

This abstraction separates the generated computational logic from the FMU interface.

FMU Interface Generation
------------------------

To interface with PythonFMU, a temporary Python file is generated automatically. This file:

- Defines the FMU class
- Imports required modules
- Registers FMI variables (inputs, outputs, parameters)
- Connects the FMU interface to ``FmuRuntime``

PythonFMU uses this file to generate the final FMU, including the corresponding ``modelDescription.xml`` which defines the FMU interface.

FMU Build Process
-----------------

The FMU is generated by executing the following PythonFMU build command::

    pythonfmu build -f temp.py src/faultdiagnosistoolbox

This command packages:

- The generated FMU interface
- The residual computation logic
- Required parts of ``faultdiagnosistoolbox``

After generation, the temporary Python file is removed and the output FMU file is verified.

Usage and Limitations
---------------------

The resulting FMU is a portable artifact that can be distributed and imported into external simulation environments. In this project, validation focused on Matlab Simulink.

A limitation of the generated FMU is its dependency on an external Python environment. The target system must provide:

- Python 3.10
- Required Python dependencies

This reduces portability compared to fully compiled FMUs.

Setup and Execution
-------------------

To run the FMU in Matlab Simulink, additional configuration is required to ensure correct library linking and Python integration.

Read :doc:`run_fmu_in_matlab` for detailed setup instructions.
